# Garmin QR GitHub Pages 복구본

이 폴더 내용만 GitHub 저장소 루트에 올리면 정적 페이지로 실행됩니다. `index.html`이 루트에 있어야 합니다.

**원본 완전 복제본이 아닙니다.** 사용자가 저장한 실제 HTML DOM을 사용했으나 첨부되지 않은 원본 `style.css`, `app.js`, `codec.js`, `qrcode.js`, `event-config.js`, `theme.js`, `garmin-design.png`는 복구하거나 대체했습니다. 따라서 원본 디자인과 동작이 완전히 동일하다고 보장하지 않습니다. 메인 배너는 사용자가 제공한 디자인 이미지에서 상단 행사 아트 부분만 잘라 사용했습니다. 이미지에 함께 포함된 예시 입력 화면은 실제 웹 입력란과 겹치지 않도록 제외했습니다.

QR 데이터는 과거 개발 보고서의 데이터 규약 v1(21801 + 이름 수 + HHMMSS + Unicode codepoints 7자리씩 + mod97)을 재구현했습니다. **이전에 운영했던 최종 웹사이트의 QR과 실제 스캔 비교 및 PT-218/각인매니저 연동 검증 전에는 현장 사용하지 마세요.**

민감정보: 패키지 내 비밀키·토큰·개인 파일을 검사했습니다. 사용자 입력 데이터는 브라우저에서만 처리됩니다.

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root) → Save.

## 특수문자 입력 지원
- 한글, 영문, 숫자 및 일반 특수문자(`- _ . & / ( ) + # @ ! ♥ ♡ ★` 등), 이모지 입력을 QR에 숫자로 변환합니다.
- NFC 정규화 후 유니코드 코드포인트 기준 1~24자 제한. 일부 이모지는 여러 코드포인트를 사용합니다.
- 줄바꿈, 탭, 제어문자는 차단합니다. 이름 앞뒤 공백은 제거하고 내부 공백은 유지합니다.
- QR 데이터 형식은 기존 v1과 동일합니다. 수신측도 유니코드 코드포인트를 복원할 수 있어야 합니다.
- **실제 각인**: QR 복원 가능과 폰트/레이저 소프트웨어에서 특수문자가 표현되는 것은 별개입니다. 현장 기기에서 지원 글꼴을 테스트하세요.


## xTool 문자 안전 정책
- 한글, 영문, 숫자, 공백과 `- . _ ( ) / & + * @`만 접수 허용
- 하트/별/이모지 및 미검증 특수기호는 차단
- 최종 각인 가능 여부는 **운영 PC의 xTool Studio 폰트와 자동 입력 방식**에 따라 달라지므로 실기 테스트 필수
- QR 데이터 프로토콜 v1은 변경하지 않음
